# GitHub and CI

All claims below as of 2026-11-24 unless dated otherwise.

- All repos live under the `marcin-sieradzki` GitHub account.
- Merging: Marcin approves each merge. "Merge when green" covers the PRs he named then, not later ones.

## Mylder

- `pr-body.yml` fails a PR whose body has `claude.ai/code/session_` or "Generated with [Claude Code]". A project-thread link (`claude.ai/code/project/...`) passes.
- `ci.yml` fails if any commit message has a `Claude-Session:` line. Keep only `Co-Authored-By`.
- Some PR tools append a "Generated by Claude Code" footer on their own: read the PR body back after creating it and remove the footer.
- The pr-body run from when the PR opened stays red after the body is fixed. Check the runs by hand and merge on the passing rerun.
- Fixing a commit message needs a force-push, which needs Marcin's explicit go-ahead. Write the commit right the first time.

## Perron

- No attribution rules. A change to what `@mylder/perron` or `@mylder/perron-mcp` ships needs a changeset (`npx changeset`).
